# CAPITAL: Business Empire
Офлайн-игра для Android на Godot 4.6.3. Работа ведётся только в
[elcin31/capital-31](https://github.com/elcin31/capital-31).

Игровая цепочка: создание героя и компании → один из пяти городов → аренда →
изометрический офис → комнаты и мебель → сотрудники → продукт / товар /
производство → продажи → финансовые отчёты → переговоры → инвестиции →
филиалы → сохранение / загрузка → карьера после банкротства.

APK/ZIP публикуется в Releases этого репозитория. Подпись тестовая, для личной
установки; минимум Android 7.0 / API 24, OpenGL ES 3.0. Архитектуры ARM64,
ARMv7 и x86_64. Интернет и внешние сервисы игре не нужны.

## Проверки
- Экономика: `godot --headless --path game --script res://tests/economy_test.gd`
- Сквозной UI: `xvfb-run godot --path game --audio-driver Dummy --resolution 1440x810 --script res://tests/gui_test.gd`
- Дизайн-прототипы: `godot --path game -- --capture` (desktop QA, создаёт новую тестовую сессию).
- Android-сборка: `bash tools/build_release.sh`; перед первым запуском установлен Godot 4.6.3 и Java 21.
- JSON-результаты фактически выполненных проверок — в `docs/QA-*.json`.

Архитектура — `docs/ARCHITECTURE.md`, дизайн — `docs/design/`.
Не заявляем замер 30 FPS на реальном Redmi Note 12. Городские панорамы
содержат нарисованных фоновых прохожих; симулируемые сотрудники находятся
в офисе. Комнаты в UI — 4×4; календарь встреч и обещания инвесторам пока
не реализованы. Основной связный игровой цикл трёх отраслей реализован.
