# Фактически выполненные проверки

Дата: 21 октября 2026. Это отчёт о выполненных проверках, а не перечень
планируемых тестов. Сборка предназначена для личного тестирования.

## Экономика и интерфейс

- 163 проверки экономики, 0 ошибок: `QA-ECONOMY.json`.
- 49 проверок интерфейса, 0 ошибок: `QA-GUI.json`.
- Загрузка сохранения в новом процессе, проверка выручки и инвестиционного
  раунда, затем продвижение времени: `QA-RESTART.json`.

Экономические тесты проходят полный цикл продаж в IT, торговле и производстве.
Проверены баланс, денежные потоки, начисления, себестоимость, налог, ставки
кредитов, доли, банкротство, новая компания прежнего основателя, филиалы,
конкуренты, детерминированность скоростей и безопасное сохранение.

GUI-тест использует реальные события нажатия и отпускания указателя в Godot,
а также события сенсорных жестов. Проверены четыре соотношения сторон:
16:9, 18:9, 19.5:9 и 20:9. Этот тест выполнен на desktop/Xvfb; он не заменяет
проверку APK. Снимки: `qa/desktop/`.

## Android

Среда: Android 11 / API 30, x86_64, Android Emulator 37.3.5, программная
эмуляция CPU (TCG), host OpenGL через Mesa. Полный пользовательский сценарий
выполнен на Android-кандидатах сборки с помощью настоящих ADB-нажатий:

1. Созданы и изменены герой, город и компания.
2. Арендован офис, построена комната, куплено рабочее место, нанят сотрудник.
3. Создан и выпущен SaaS-продукт, получены клиенты и выручка при ×5 / ×10.
4. Просмотрены P&L и Cash Flow, найдена инвестор, представлены финансовые
   показатели, сделано встречное предложение и заключена сделка.
5. Проверены корпоративный остаток, личные деньги и размытие долей.
6. Записан ручной слот; при сворачивании записан автоматический слот.

Во время сценария Wi-Fi и мобильные данные эмулятора отключены.
Итоговое сохранение извлечено из приватного каталога приложения для проверки
баланса и сверки денежных потоков. Этот доступ нужен только QA; установка
APK пользователем не требует root или ADB.

Обновление и повторный запуск финального APK отражены отдельно в
`QA-ANDROID.json`. Снимки этапов находятся в `qa/android/`, проверенные
числовые результаты — в `qa/android/SAVE-STATE.json`.

На физическом Android-смартфоне тест не проводился. 30 FPS на Redmi Note 12
не измерены. Настоящий двухпальцевый жест и поворот физического устройства
не проверены; жесты камеры проверены событиями GUI, ориентация зафиксирована
в Android-манифесте. Длительная балансировка песочницы остаётся открытой.
